# Contabilidad (React + Vite + Supabase)
1. Pegue supabase/schema.sql en Supabase > SQL Editor (cambie correo y contraseña del admin).
2. Edite src/config.ts con su Project URL y clave pública.
3. Suba la carpeta a GitHub y conéctela a Netlify (build: npm run build, publish: dist).
No requiere buckets. Documentos no fiscales.
